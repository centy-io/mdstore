# Add CI GitHub Action for package validation and crates.io publishing

## Summary

Set up a GitHub Actions CI workflow that validates the `mdstore` crate and publishes it to crates.io.

## Requirements

### Validation (on every push and PR)

* Run `cargo fmt --check` to enforce formatting
* Run `cargo clippy` with the project’s strict lint configuration (pedantic + deny rules)
* Run `cargo test` to ensure all tests pass
* Run `cargo build` to verify successful compilation
* Test against the minimum supported Rust version (MSRV: 1.70)
* Run `cargo package --list` / `cargo package` dry-run to validate the package is publishable

### Publishing (on tag/release)

* Trigger on version tags (e.g., `v*.*.*`)
* Run full validation suite before publishing
* Publish to crates.io using a `CARGO_REGISTRY_TOKEN` secret
* Optionally create a GitHub Release with changelog notes

## Acceptance Criteria

* [ ] `.github/workflows/ci.yml` exists with validation jobs
* [ ] `.github/workflows/publish.yml` exists (or a publish job in ci.yml) triggered on version tags
* [ ] All clippy lints from `Cargo.toml` are respected in CI
* [ ] MSRV (1.70) is tested
* [ ] `CARGO_REGISTRY_TOKEN` secret is documented in README or CONTRIBUTING guide
