# Add Husky with pre-commit, pre-push, and commitlint checks

## Summary

Set up Husky to enforce code quality and commit conventions via Git hooks.

## Requirements

### Pre-commit hook

* Run linting and formatting checks before each commit
* Fail fast on lint errors to prevent bad code from being committed

### Pre-push hook

* Run the full test suite before pushing to remote
* Prevent pushing code that breaks tests

### Commitlint

* Enforce Conventional Commits format on all commit messages
* Configure @commitlint/config-conventional as the base ruleset
