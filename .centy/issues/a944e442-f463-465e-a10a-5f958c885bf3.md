# custom_fields serialized as nested key rather than flattened into frontmatter

In types.rs lines 32-33, custom_fields is serialized as a nested customFields: key in the YAML frontmatter rather than being flattened to the top level. This is consistent but means all custom fields are namespaced. Consider whether top-level flattening would be more ergonomic for users editing files by hand.
