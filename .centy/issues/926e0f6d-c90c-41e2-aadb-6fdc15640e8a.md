# Skip empty H1 heading in mdstore when title is blank

## Bug

When a comment is created, the markdown file contains an empty H1 heading because `mdstore` unconditionally writes `# {title}` even when title is empty.

```markdown
---
item_type: issues
author: Ofek
---

#

body text here
```

## Root Cause

`mdstore` `frontmatter.rs:146` always renders `# {title}` regardless of whether title is blank.

## Fix

Skip the H1 line when title is empty/whitespace-only.
