# duplicate() does not check the duplicate feature flag before proceeding

In storage.rs, the duplicate() function does not check config.features.duplicate before creating a copy. This allows duplication even when the feature is explicitly disabled in the type config. By contrast, move_item() correctly validates source_config.features.move_item at the start and returns StoreError::FeatureNotEnabled if not enabled. The duplicate() function should do the same: check config.features.duplicate early and return FeatureNotEnabled if false.
