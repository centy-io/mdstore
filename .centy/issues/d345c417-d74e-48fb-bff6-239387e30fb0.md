# list() silently skips malformed .md files, masking potential data corruption

In storage.rs, the list() function continues on parse errors for individual .md files without emitting any warning. A malformed file (corrupted frontmatter, missing fields) is silently ignored. This could mask data corruption. At minimum, a tracing::warn should be emitted when a file is skipped due to a parse error.
