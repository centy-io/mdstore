# Auto-derive plural name using a pluralizer instead of requiring manual input

The TypeConfig currently requires a ‘plural’ field (e.g., name: “Issue”, plural: “issues”). This is redundant and error-prone. Instead, we should use the ‘pluralizer’ crate to automatically derive the plural form from the ‘name’ field. The ‘plural’ field should become optional, only needed for irregular plurals or overrides.
