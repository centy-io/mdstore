# Display number reconciliation relies on string-sorted created_at timestamps

In reconcile.rs, display number conflict resolution sorts items by their created_at string values. This works correctly only because timestamps are in ISO 8601 format, which sorts lexicographically. This invariant is not documented or enforced — if a timestamp were ever written in a different format, reconciliation order would silently break. Consider parsing to chrono DateTime before sorting, or adding a validation check.
