# move_item raw YAML parsing for field preservation adds complexity

In storage.rs, move_item() uses raw YAML parsing (serde_yaml::Value) to preserve unknown/custom fields during the move operation rather than going through the typed Frontmatter struct. While this correctly preserves fields that aren’t part of the known schema, it adds maintenance complexity and bypasses the type system. Consider whether a serde flatten approach or an explicit unknown-fields map on Frontmatter could achieve the same preservation with less raw manipulation.
